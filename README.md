
## 📌 Project Overview

This project presents an end-to-end **Retail Sales Data Analysis** performed using Microsoft Excel.

The objective was to transform raw retail transaction data into meaningful business insights by using Excel formulas, PivotTables, KPIs, and visualizations.

The analysis focuses on understanding sales performance across **regions, products, months, and salespeople**, and identifying the areas contributing most strongly to overall sales.

---

## 🎯 Project Objectives

The main objectives of this project were to:

- Analyze overall retail sales performance.
- Calculate important sales KPIs.
- Compare sales performance across regions.
- Identify high-performing products.
- Analyze monthly sales trends.
- Analyze salesperson performance.
- Use conditional Excel formulas for business analysis.
- Create PivotTables for summarizing large amounts of data.
- Build a simple and professional sales dashboard.
- Convert raw transaction data into actionable business insights.

---

## 🗂️ Dataset

The dataset contains **240 retail sales records**.

Key fields included in the dataset are:

- Order / Date information
- Product
- Quantity
- Total Sales
- Region
- Salesperson

The original data is maintained in the `Raw_Data` worksheet so that the source information remains separate from the analysis.

## 📑 Workbook Structure

The Excel workbook is organized into the following sections:

### 1. Raw_Data

Contains the original retail transaction data.

This sheet is kept separate from calculations to maintain data integrity.

### 2. Analysis

Contains formula-based analysis using:

- `SUMIFS`
- `COUNTIFS`
- `AVERAGEIFS`

The analysis includes regional sales, order counts, average sales, and other KPI calculations.

### 3. Summary

- Total Sales

# 🔎 Analysis Performed

## 1. Regional Sales Analysis

The project uses `SUMIFS`, `COUNTIFS`, and `AVERAGEIFS` to analyze regional performance.

The analysis compares:

- Total sales by region
- Number of orders by region
- Average sales by region

### Key Finding

**Central** was the highest-sales region in the analyzed dataset.

---

## 2. Product Sales Analysis

Product-level sales were analyzed using PivotTables to identify products contributing the most to total revenue.

### Key Finding

**Laptop Stand** was the highest-sales product.

This information can help businesses make better decisions regarding inventory, promotions, and product focus.

---

## 3. Monthly Sales Trend

Sales were analyzed by month using PivotTables and visualized using a line chart.

### Key Finding

**June** recorded the highest monthly sales.

Understanding monthly patterns can help businesses plan inventory, marketing campaigns, and staffing requirements.

---

## 4. Salesperson Analysis

The dataset was also analyzed at the salesperson level to provide an additional view of sales performance.

This allows management to identify stronger-performing salespeople and understand differences in sales contribution.
